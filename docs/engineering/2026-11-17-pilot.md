## Design and approaches

Use the recovered real app with local authentication and persistent PostgreSQL.
The alternative fixture preview resets on reload and cannot prove account or
storage behavior; the user chose the real local pilot. A hosted environment
introduces credentials and publication requirements that today's local test does
not need. Windows uses the same Expo app in a browser, not the separate Next app.
Align native dependencies to SDK 58 for the installed iPhone client.

Keep emulator mode explicit, development-only, and tied to `demo-vysion-pilot`.
Never weaken production authentication. Only the new database may be initialized
or migrated. Persist local emulator accounts across restarts. Launch scripts must
work with Node even when the system npm shim is broken. Do not claim device
acceptance before the user actually opens the app.
